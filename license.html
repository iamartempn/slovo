4. Сторонние компоненты и модели

4.1. В Программу входят компоненты с открытым исходным кодом: WhisperKit (лицензия MIT), фрагменты swift-transformers (лицензия Apache 2.0) и llama.cpp (лицензия MIT). Их лицензии действуют наравне с этим соглашением; полные тексты — в файле «Сторонние компоненты», который поставляется с Программой.

4.2. Нейросетевые модели не входят в установочный файл. По вашему выбору Программа скачивает их с сайта Hugging Face: модели распознавания речи Whisper (лицензия MIT, OpenAI и Argmax) и языковую модель Qwen3-4B (лицензия Apache 2.0, Alibaba Cloud). Модели распространяются их авторами на условиях этих лицензий.
